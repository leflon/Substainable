# Sub'stainable

## Overview
Sub'stainable is a web application designed to help users manage and monitor their subscriptions, with an accent on ecological challenges. It consolidates data from popular subscription platforms such as Netflix, Amazon Prime, Spotify, and more, providing a centralized view of your subscription expenses and usage.

## Features
- **Subscription Management**: Add, edit, and delete subscriptions.
- **Usage Tracking**: Monitor consumed data and usage statistics for supported platforms.
- **Expense Overview**: View a summary of your monthly subscription costs.
- **User-Friendly Interface**: Simple and intuitive design for seamless navigation.
